# Publicar gratis con GitHub Pages

Esta es la opcion gratis mas estable para que la pagina quede visible en internet y puedas modificarla despues.

## 1. Crear cuenta

Entra en:

```text
https://github.com
```

Crea una cuenta gratuita o inicia sesion.

## 2. Crear repositorio

Pulsa `New repository` y usa este nombre:

```text
vicentegalve-el-panollo
```

Marca el repositorio como `Public`.

## 3. Subir archivos

Dentro del repositorio, pulsa:

```text
Add file -> Upload files
```

Sube estos archivos de esta carpeta:

```text
index.html
styles.css
script.js
.nojekyll
```

Puedes subir tambien:

```text
EDITAR_WEB.md
PUBLICAR_GRATIS_GITHUB.md
```

No hace falta subir:

```text
dev-server.js
publicar-internet.ps1
COMO_PUBLICAR.md
server.log
server.err.log
tools
```

Pulsa `Commit changes`.

## 4. Activar GitHub Pages

En el repositorio:

```text
Settings -> Pages
```

En `Build and deployment`:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

Pulsa `Save`.

## 5. Enlace final

Tu pagina quedara con una direccion parecida a esta:

```text
https://TU-USUARIO.github.io/vicentegalve-el-panollo/
```

Ese enlace es gratis, fijo y facil de compartir.

## 6. Modificar despues

En GitHub, abre el archivo que quieras cambiar, pulsa el lapiz, edita y guarda con `Commit changes`.

Los cambios apareceran en la web automaticamente despues de unos segundos o minutos.

## Nota sobre Google

Google puede tardar dias o semanas en encontrar una pagina nueva. Para ayudar, comparte el enlace en redes, WhatsApp, Facebook, YouTube o paginas relacionadas con la jota aragonesa.
